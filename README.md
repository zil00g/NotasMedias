# NotasMedias
Calculo notas medias entre evaluación continua y prueba de síntesis 

Para realizar el calculo se solicita al usuario por un lado la nota de la evaluación continua y el porcentaje del valor de esta evaluación.
Por otro lado se solicita al usuario la nota de la prueba de sintesis y la nota de corte para que esta pueda hacer media con la evaluacigeón continua.

Si supera la nota de corte el script genera el resultado de la media entre ambas evaluaciones de lo contrario arrojara nuevamente la puntuación de la prueba de sintesis
